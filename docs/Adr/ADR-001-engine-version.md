# ADR-001: Движок и версия — Unity 6.3 LTS

Дата:    2026-08-17
Статус:  Принято

## Контекст

Проект рассчитан на 24 месяца разработки одним программистом. Движок и его
версия фиксируются один раз в самом начале, потому что смена версии
посреди производства обходится в недели непредсказуемой отладки —
дороже почти любого другого решения в проекте.

На момент выбора доступны: Unity 6.0 LTS (октябрь 2024, поддержка до
октября 2026) и Unity 6.3 LTS (декабрь 2025, первый LTS-релиз после
6.0, поддержка до декабря 2027). Между ними — несколько Update-релизов
(6.1, 6.2), которые не являются LTS и не рекомендованы для проектов,
фиксирующихся на версии.

## Рассмотренные варианты

1. **Unity 6.0 LTS.** Поддержка заканчивается в октябре 2026 — раньше,
   чем в этом проекте будет пройдена даже фаза 2. К моменту релиза
   версия была бы без обновлений уже больше года.
2. **Unity 6.3 LTS.** Поддержка до декабря 2027 — покрывает весь
   производственный цикл (24 месяца) с запасом на постпродакшн и
   патч 1.1.
3. **Update-релиз (6.1 / 6.2) как база.** Отклонён сразу: Update-релизы
   не LTS, обновляются чаще и не предназначены для долгого
   производственного цикла.

## Решение

**Unity 6.3 LTS, патч `6000.3.21f1`**, зафиксирован в
`ProjectSettings/ProjectVersion.txt`. Обновление версии не производится
без отдельного ADR.

Правило обновления: внутри линии 6.3 допускаются только патч-обновления
(например, `6000.3.21f1 → 6000.3.22f1`) для устранения конкретных
багов, мешающих работе. Переход на следующую LTS-линию (Unity 7 или более позднюю)
не рассматривается до завершения версии 1.0 и обсуждается отдельным ADR.

## Последствия

+ Поддержка движка не заканчивается до конца производственного цикла.
+ Доступны Box2D v3 и связанные 2D-улучшения из 6.3 — не критично для
  проекта, но не мешает.
+ Стабильная база для полутора-двух лет работы без вынужденных миграций.
- Более новая, чем 6.0 LTS: меньше материалов и готовых ответов на форумах
  на момент старта, чем было бы для более старой версии.
- Если Unity 7 LTS выйдет раньше декабря 2027 и оговорит более раннее
  прекращение поддержки 6.3 — потребуется пересмотр (риск низкий,
  Unity исторически не сокращает заявленные сроки LTS).
